This section documents how StarIntel components work today, as far as the
editorial desk can verify them. Documentation pages carry a revision badge
and, for aggregated pages, the source repository and revision they came
from.

* Where to start

- The [[id:docs-server-overview][StarIntel Server overview]] — the Common Lisp runtime: CouchDB,
  RabbitMQ, Sento actors, and the HTTP API.
- [[id:docs-server-ingest][Ingest and dataflow recursion]] — how a document moves through the
  pipeline and how actors expand the graph.
- [[id:docs-documents-schema][The v0.9 document model]] — typed documents, provenance, and design
  invariants.

* Scope and authority

StarIntel Server remains the runtime authority for its own behavior; these
pages summarize its documented design and link to the canonical sources.
When the server documentation changes, aggregated pages on this site carry
the revision they were taken from, and the editorial desk re-verifies
hand-written pages before bumping their revision.
