* External repositories

Every public StarIntel repository is aggregated here, read-only and
revision-pinned: each contributes its README as a landing page plus its
=docs/= and =doc/= Org trees where present — the server's generated API
reference included. The current set covers StarIntel Server, Quasar, Auto
Research, Auto Dig, Star-Lang, starintel-doc, a0-symbolics, star-cl,
cl-couch, star-bbpd, starintel-client, and RAGE; the sidebar lists
whatever the build pulled in.

* Scope and authority

StarIntel Server remains the runtime authority for its own behavior; these
pages summarize its documented design and link to the canonical sources.
When the server documentation changes, aggregated pages on this site carry
the revision they were taken from, and the editorial desk re-verifies
hand-written pages before bumping their revision.
