* Start with the complete installation tutorial

The maintained path is [[file:../tutorials/local-install.org][Complete local installation]]. It covers pinned
source, all seven required base-stack file secrets, Nix-built images, Compose
health checks, one-time administrator bootstrap, scoped keys, ingest/read-back,
persistence and safe shutdown.

The earlier quickstart on this URL omitted the auth pepper/bootstrap files and
showed old unauthenticated document routes. Those examples are retired. For
new integrations, discover =/client-manifest.json= and =/openapi.json= and use
the maintained client. Do not copy a legacy route or relabel an old document.

* If you only want to learn

You do not need a server to start. [[file:../tutorials/getting-started.org][Create a local workspace]] using
=starintel-intro=, then [[file:../tutorials/mcp.org][connect MCP]] or [[file:../tutorials/cli.org][learn the CLI]].
If you already have a server URL and key, skip installation and follow
[[file:../tutorials/api-keys.org][the API-key tutorial]].
