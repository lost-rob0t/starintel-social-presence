# Org/dslide presentation generation

Use `youtube/video-source/<slug>/present.org` for slides and `script.org` for spoken notes.

1. Start from verified tutorial/article source material.
2. Keep slide headings short and one idea per slide.
3. Put commands, expected output, and demo checkpoints in explicit blocks or checklists.
4. Cross-link script and presentation headings when useful.
5. Reference curated assets under the video's `assets/images/` directory.
6. Do not generate or commit rendered video.
