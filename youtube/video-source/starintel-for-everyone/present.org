* Search finds pages. StarIntel keeps evidence.

#+begin_example
search
  -> page
  -> tab
  -> notes
  -> where did this claim come from?
#+end_example

StarIntel turns observations into typed, source-preserving documents that can
be linked, searched, revisited, and operated by actors.

* The whole idea in three pieces

#+begin_example
DOCUMENTS  ->  ACTORS  ->  GRAPH
 memory        work         operator view
#+end_example

- Documents keep identity, data, sources, evidence, provenance.
- Actors consume targets/documents and emit more documents or relations.
- Quasar projects the corpus into an investigation/operator workspace.

* Actors do the repetitive work

#+begin_example
target/document
      |
      v
    ACTOR
      |
      +--> document
      +--> relation
      +--> target
      `--> actor event
#+end_example

Actors can be local, browser-based, or external services.

* Quasar is where the human drives

#+begin_example
documents + relations
        |
        v
   QUASAR / GRAPH
        |
        +--> inspect
        +--> search
        +--> traverse
        +--> edit
        `--> create new work
#+end_example

The graph is a projection of the documents.

The graph is not proof by itself.

* Generate local secrets

#+begin_src sh
install -d -m 0700 secrets

openssl rand -base64 32 > secrets/couchdb_password
openssl rand -base64 48 > secrets/couchdb_secret
openssl rand -hex 24 |
  tr '[:lower:]' '[:upper:]' > secrets/erlang_cookie

openssl rand -base64 32 > secrets/rabbitmq_password
openssl rand -base64 32 > secrets/valkey_password
openssl rand -base64 48 > secrets/auth_pepper
openssl rand -base64 48 > secrets/auth_bootstrap_secret

chmod 0600 secrets/*
#+end_src

* Bootstrap one local API credential

#+begin_src sh
bootstrap_secret="$(<secrets/auth_bootstrap_secret)"

curl --fail --silent --show-error \
  --request POST \
  --header 'Content-Type: application/json' \
  --header "X-Star-Bootstrap-Secret: $bootstrap_secret" \
  --data '{"owner":"youtube-demo"}' \
  http://127.0.0.1:5000/auth/bootstrap |
  tee /tmp/starintel-bootstrap.json

api_key="$(jq -r '.api_key' /tmp/starintel-bootstrap.json)"

* What is still rough

- StarIntel is experimental.
- Some actor implementations are private.
- Quasar UI standalone is not the full connected runtime.
- Some server compatibility paths are still legacy.
- Local development is not a hardened Internet deployment.

No fake polish.
